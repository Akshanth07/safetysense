# SafetySense (Arduino Dashboard)

Real-time Arduino sensor dashboard.

## Overview

This project includes:
- A real-time dashboard for Arduino sensors (`server.js`) built with Node.js and Express.
- Supervised anomaly detection for sensor data (`supervised_anomaly_detection.py`).

## Installation

1. Install Node.js dependencies:
   ```bash
   npm install
   ```

2. Run the server:
   ```bash
   npm start
   ```

## Requirements
- Node.js
- Python (for anomaly detection script)
